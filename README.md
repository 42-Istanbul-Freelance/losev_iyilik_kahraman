## ✨ Özellikler

### 📚 Eğitim Modülleri

Oyun 6 farklı eğitim modülü içerir:

1. **❤️ Yardımlaşma** - Birbirine yardım etmenin önemi
2. **🧼 Sağlık ve Hijyen** - El yıkama ve temizlik alışkanlıkları
3. **🥗 Dengeli Beslenme** - Sağlıklı beslenme ve su tüketimi
4. **🎁 Paylaşma** - Paylaşmanın değeri ve önemi
5. **🌟 Gönüllülük** - Karşılıksız yardım etme bilinci
6. **⭐ Günlük Alışkanlıklar** - Uyku, hareket ve diş fırçalama rutinleri

Her modül:
- 2-3 eğitici ders içerir
- Her ders sonunda çoktan seçmeli sorular sunar
- Karakterli animasyonlarla desteklenir
- Günlük görev içerir

### 🎮 Oyun Mekanikleri

- **XP Sistemi**: Doğru cevaplar ve görev tamamlama ile puan kazanma
  - Her modül tamamlama: 50 XP
  - Günlük görev tamamlama: 25 XP
- **Seviye Sistemi**: XP biriktirerek seviye atlama (her 100 XP = 1 seviye)
- **Seri Sistemi**: Ardışık günlerde oyuna girerek seri tutma 🔥
- **Rozet Sistemi**: Modülleri tamamlayarak rozet kazanma 🏆
- **İlerleme Takibi**: Tamamlanan modüller ve görevlerin kaydı

### 🎨 Görsel ve Ses

- Kenney Toon karakterleri ile çekici görseller
- Farklı pozlar ve karakterler (erkek/kadın)
- Arka plan müziği ve ses efektleri
- Renkli ve çocuk dostu arayüz
- Mobil cihazlar için optimize edilmiş (540x960 çözünürlük)

### 💾 Veri Saklama

- Otomatik ilerleme kaydı
- Kullanıcı istatistikleri (XP, seri, rozetler)
- Tamamlanan modül ve görevlerin takibi
- Günlük görev takip sistemi

## 🚀 Kurulum

### Gereksinimler

- [Godot Engine 4.6](https://godotengine.org/download) veya üzeri
- İşletim Sistemi: Windows, Linux, macOS
- Dışa aktarım için: Android/iOS SDK (mobil için)

### Projeyi Çalıştırma

1. **Depoyu klonlayın:**
   ```bash
   git clone https://github.com/kullaniciadi/losevgame.git
   cd losevgame
   ```

2. **Godot'da açın:**
   - Godot Engine'i başlatın
   - "Import" (İçe Aktar) butonuna tıklayın
   - `project.godot` dosyasını seçin
   - "Import & Edit" butonuna tıklayın

3. **Oyunu çalıştırın:**
   - F5 tuşuna basın veya sağ üstteki "Play" butonuna tıklayın

### Mobil Cihazlara Dışa Aktarma

1. **Android için:**
   ```bash
   # Android SDK kurulumu gerekir
   # Project > Export > Android > Export Project
   ```

2. **iOS için:**
   ```bash
   # macOS ve Xcode gerekir
   # Project > Export > iOS > Export Project
   ```

## 🎓 Modül İçeriği Düzenleme

Oyunun eğitim içeriğini düzenlemek için `content/modules.json` dosyasını kullanabilirsiniz.

### Modül Yapısı

```json
{
  "id": "modul_id",
  "title": "Modül Başlığı",
  "icon": "🎨",
  "color": "#FF6B8A",
  "lessons": [
    {
      "id": "ders_id",
      "text": "Ders açıklama metni",
      "character": "malePerson",  // veya "femalePerson"
      "pose": "cheer0",           // Karakter pozu
      "question": {
        "text": "Soru metni?",
        "options": [
          {"text": "Doğru cevap", "correct": true},
          {"text": "Yanlış cevap 1", "correct": false},
          {"text": "Yanlış cevap 2", "correct": false}
        ]
      }
    }
  ],
  "daily_task": "Günlük görev açıklaması"
}
```

### Mevcut Karakter Pozları

- `cheer0`, `cheer1` - Mutlu/Alkışlama
- `hold` - Bir şey tutar pozisyon
- `show` - Gösterme pozu
- `think` - Düşünme pozu
- `wave` - El sallama
- `wide` - Kollar açık
- `side` - Yan duruş

## 🔧 Geliştirme

### Autoload Sistemleri

Proje 4 global sistem kullanır:

1. **GameData** - Oyuncu verileri, XP, seri, rozet yönetimi
2. **LessonBridge** - Modüller arası veri aktarımı
3. **UITheme** - Tutarlı UI stili ve tema yönetimi
4. **AudioManager** - Müzik ve ses efekti yönetimi

### Yeni Modül Ekleme

1. `content/modules.json` dosyasına yeni modül ekleyin
2. Gerekli karakter görsellerini `assets/kenney_toon/` içinden seçin
3. Ses efektlerini `assets/audio/` içine ekleyin (opsiyonel)
4. Oyunu çalıştırın - yeni modül otomatik olarak görünecektir

### Yeni Özellik Ekleme

```gdscript
# GameData.gd içinde yeni özellik
func yeni_ozellik():
    # Kodunuz
    save_data()  # Değişiklikleri kaydet
```
